# 本地订阅模组与桌宠 v7.1 卡牌对照

v7.1 按用户反馈调整冷静头脑：移除模组实体冰层，改为原版可见头部变蓝并飘雪。头部与夹头重新通过可见 SpineSprite 手动求值，修复隐藏 Sprite 不更新骨骼导致坐标固定的问题。1156 帧头部锚点与原版画面一致，误差小于 0.005 像素；夹头位于头部和围巾后方。以下冷静头脑表格描述为 v7 的历史实现。

参考：page 的 More Defect Animations v0.17.1，Steam 创意工坊 3810696310。只读检查本机订阅的资源、绑定数据、几何数据和动画代码。游戏和模组安装目录未修改；桌宠运行不加载模组 DLL，也不需要启动游戏。

本轮调整桌宠已有 36 张牌中，与模组重合的 9 张。模组共支持 21 张，其余 12 张尚未加入桌宠。

| 卡牌 | 本地内容与具体调整 |
| --- | --- |
| 冷静头脑 | 根据 NativeCoolheaded、头部网格和骨骼权重，将实际冰层贴图逐帧绑定原版六种角色动作。1156 帧；0.23 秒出现，完整保持 2 秒，0.6 秒消退；重复使用平滑刷新。 |
| 充电 | 根据 NativeChargeBattery 的红蓝夹头、头部绑定、预弯电线和 cable-prefabs 数据。夹头跟随头部，电线垂到地面并连续摆动；0.3 秒出现、保持 2 秒、0.6 秒淡出。 |
| 缓冲 | 根据 NativeBuffer 的身后牌子、支杆和三块破碎贴图；0.32 秒翻起。桌宠每次消耗次数时牌子回弹，最后一次破裂；碎片完成后消失，重新获得缓冲不会抹掉旧碎片。 |
| 碎片整理 | 使用原模组 98 块彩色墙面几何、六面配色、44 号蓝块补洞及 696 条扫描边。每次 1.8 秒，连续使用各自播放。 |
| 全息影像 | 参考 ShadowVisual，单个蓝色本体投影延迟 0.12 秒，按开启、保持、关闭组成 3 秒周期。其他卡牌不中断它，头冰和夹头不会被复制；再次施放重开投影。 |
| 双重释放 | 保留实际球种对应的雷电、冰霜、黑暗、等离子表现；两次激发间隔 0.24 秒，与本地模组时序对照。 |
| 冰之长枪 | 根据本地晶体环、六色面与八道风的数据重建二维投影。飞行 0.30 秒，接触保持 0.18 秒再破裂；风环扩到 2.3 倍、继续滑行后淡出；使用原模组 16 帧雪粒和 16 帧冰雾。 |
| 陨石打击 | 根据 NativeMeteor/陨石效果组织一次大冲击，白色尖端、青金内部与暗色碎屑，之后三路等离子轨迹进入球槽。 |
| 内核加速 | 按 TurboNativeRig 从原版 die 动作分离电弧，核心沿用 process；周期 47/30 秒。切换卡牌可收束核心状态，已经发出的电弧独立完成。 |

二维透明桌宠对墙面泛光、冰枪三维投影、风环细分做了适配，并非游戏引擎着色器的逐像素复制。桌宠的次数、储能、能力消耗等互动规则继续沿用现有设计，例如缓冲是三次出牌消耗且 15 秒到期。

来源文件及哈希见 assets/mod-sources.json。源码包含准备好的贴图、动作数据和生成的 C#，可以直接构建。重新从游戏生成头部和电弧帧需要本机游戏运行库及本地订阅资源；导出脚本在 native-study，资源整理脚本为 prepare_mod_assets.py 和 render_mod_wall.py。完整反编译目录、模组 DLL 和游戏运行库不包含在发布包中。
